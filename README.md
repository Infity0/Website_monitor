# SiteMonitor Pro - Система мониторинга веб-сайтов

## Описание

**SiteMonitor Pro** — это профессиональная система мониторинга доступности веб-сайтов, построенная на Flask. Приложение позволяет отслеживать статус и производительность веб-ресурсов в реальном времени, предоставляя детальную статистику и уведомления о проблемах.

## Основные возможности

### Мониторинг в реальном времени
- **Автоматические проверки** — периодический мониторинг доступности сайтов
- **Мгновенные уведомления** — оповещения о изменениях статуса
- **Метрики производительности** — отслеживание времени ответа и кодов состояния
- **Гибкие интервалы** — настраиваемая частота проверок (от 1 минуты до 1 часа)

### Управление сайтами
- **Добавление сайтов** — простой процесс добавления новых ресурсов для мониторинга
- **Группировка и организация** — удобное управление списком отслеживаемых сайтов
- **Включение/выключение** — временная приостановка мониторинга без удаления
- **Ручная проверка** — мгновенная проверка статуса по требованию

### Аналитика и отчетность
- **Панель статистики** — обзор статуса всех сайтов на одном экране
- **Графики аптайма** — визуализация доступности за 24 часа, 7 и 30 дней
- **Детальная статистика** — анализ времени ответа и истории проверок
- **Экспорт в CSV** — выгрузка данных для внешнего анализа

### Технические особенности
- **Расписания APScheduler** — надежное выполнение периодических проверок
- **Локальный часовой пояс** — корректное отображение времени для пользователя
- **Обработка ошибок** — устойчивость к сетевым проблемам и таймаутам
- **Валидация URL** — автоматическое исправление и проверка адресов

## Технологический стек

### Backend
- **Python 3.7+** — основной язык разработки
- **Flask** — веб-фреймворк
- **Flask-SQLAlchemy** — ORM для работы с базой данных
- **APScheduler** — планировщик задач для периодических проверок
- **Requests** — HTTP-запросы для проверки сайтов
- **SQLite** — база данных (легковесная, не требует отдельной установки)
- **Pytz & tzlocal** — работа с часовыми поясами

### Frontend
- **HTML5** — семантическая разметка
- **CSS3** — современные стили с CSS переменными и градиентами
- **Bootstrap 5** — адаптивная верстка
- **Vanilla JavaScript** — клиентская логика
- **Chart.js** — построение графиков и диаграмм
- **Font Awesome** — иконки
- **Адаптивный дизайн** — оптимизация для мобильных устройств

## Архитектура проекта

### Структура базы данных
- **Website** — информация о отслеживаемых сайтах
- **WebsiteCheck** — история проверок с метриками производительности

### Основные модули
- **app.py** — основной файл приложения с маршрутами и API
- **models.py** — модели базы данных
- **config.py** — конфигурация приложения
- **templates/** — HTML шаблоны с Jinja2
- **static/** — статические файлы (CSS, JS)

### Ключевые API endpoints
- `/api/status` — общий статус системы
- `/api/uptime-stats` — статистика аптайма
- `/api/real-status-stats` — текущая статистика статусов
- `/api/health` — проверка здоровья системы
